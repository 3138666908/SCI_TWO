# AN-10 真·完整病例敏感性分析（SEN-5）

- 定义：从全量基线队列（age≥45 且基线 mobilsev=0）剔除任意 eCRF 成分/协变量/结局缺失者
- eCRF 成分：age, sex, bmi, waist, rhr, mvpa, smoke_now；协变量：educ, marital, drink, sbp
- 完整病例内重算 eCRF → 性别分层五分位 → 低 eCRF 参照 Cox M3（分库）
