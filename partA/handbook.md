### 2.1b HRS：harmonized ↔ RAND 对应关系（已实测验证）

- 合并键：harmonized 为 `hhidpn`（数值），RAND 为 `HHIDPN`（数值），二者**可直接对齐**。
- 已验证：harmonized 42,406 人中 **42,405 人（≈100%）能在 RAND 中找到**对应记录；RAND 另有 2,829 人不在 harmonized 内（非本研究所用，忽略）。
- 数值一致性（基线 W8 交叉核对，n 见括号）：
  - 实测 SBP：`R8BPSYS` = `r8systo`，完全一致（n=7,356，diff=0）
  - 实测体重：`R8PMWGHT` ≈ `r8mweight`，差异 ~0.0004kg（n=7,187）
  - 实测身高：`R8PMHGHT` = `r8mheight`，完全一致（n=7,418）
  - 实测 BMI：`R8PMBMI` ≈ `r8mbmi`，差异 ≤0.05（n=7,128，舍入造成）
  - 实测腰围：RAND 为**英寸**（`R8PMWAIST`），×2.54 后与 harmonized `r8mwaist`（cm）完全一致（n=7,357，diff=0）
- 结论：**HRS 的 harmonized 与 RAND 是同一批实测体格数据，仅单位/舍入不同；二者可用 `hhidpn` 对齐合并，补齐 harmonized 缺失的变量（见 §7.0）。**

## 4. 分析方案与方法学要点（来自研究计划，供提取参考）

### 4.1 基线变量
- 年龄（age）、BMI、腰围（WC）、静息心率（rHR）、身体活动（PA）、吸烟状况。
- **PA 定义**：若参与者报告每周进行一次以上的剧烈或中等强度身体活动 → 中至高强度身体活动 = 1；否则 = 0。
- **吸烟定义**：当前吸烟 = 1；否则 = 0。

### 4.2 eCRF 计算方程
男性：
```
eCRF(METs)=21.2870 + age×0.1654 − age²×0.0023 − BMI×0.2318 − WC×0.0337 − rHR×0.0390 + MVPA×0.6351 − smoking×0.4263
```
女性：
```
eCRF(METs)=14.7873 + age×0.1159 − age²×0.0017 − BMI×0.1534 − WC×0.0085 − rHR×0.0364 + MVPA×0.5987 − smoking×0.2994
```
其中 MVPA = 中至高强度身体活动（0/1），smoking = 目前吸烟（0/1）；BMI 单位 kg/m²，WC 单位 cm，rHR 单位 bpm，age 单位年。

> 实现校验点：计算后应抽几人手算对照，输出 age、age²、BMI、WC、rHR、MVPA、smoking 与 eCRF 的中间数值表，供研究者抽验。

### 4.3 分组
参与者按**性别分层五分位**（男女各自计算五分位切点）的 eCRF 分为三组：
- 低 eCRF（Q1）
- 中等 eCRF（Q2–Q3）
- 高 eCRF（Q4–Q5）

> 已确认实现方式（D9）：按性别分层——先对男性单独算 eCRF 五分位、对女性单独算 eCRF 五分位，再用各自的切点把参与者分入低/中/高三组。切点与各组样本量须输出给研究者核验。

### 4.4 协变量
- 问卷调查所得：年龄、性别、婚姻状况、教育程度、吸烟状况、饮酒状况、身体活动、医生诊断疾病（高血压、糖尿病、癌症、肺部疾病、心血管疾病）。
- 测量所得：BMI、腰围（WC）、静息心率（rHR）、收缩压（SBP）、糖化血红蛋白（HbA1c）、总胆固醇（TC）。
- **标准化（研究者已确认 D10）**：
  - 婚姻状况：**已婚或有伴侣 = 1；其他（分居/离异/丧偶/从未结婚）= 0**（二分类）
  - 教育程度：**高中以下 / 高中 / 大学及以上**（三分类）
  - 吸烟：当前吸烟者 / 曾经吸烟者 / 从不吸烟者（三分类）
  - 饮酒：**饮酒者 = 1 / 不饮酒者 = 0**（二分类，D10）
  - 身体活动：中至高强度活动（MVPA≥2 次/周）= 1 / 其他 = 0
- **缺失数据处理（研究者已确认 D7/D8）：三个库的缺失数据全部保留，不删除不填补，供后续链式方程多重插补（MICE）。**

### 4.5 结局：新发移动障碍（new-onset mobility limitation）
- 三个库均定义了统一的移动障碍：**7-item mobility `mobilsev ≥ 1`（存在任一行动困难）**（研究者已确认 D5）。
- 结局构建：基线 `mobilsev=0`（无移动障碍）的个体，在随访波次若首次出现 `mobilsev ≥ 1`，则定义为"新发移动障碍"，时间为基线至首次出现的波次间隔；期间未出现者按删失处理（使用其最后观测波次）。
- 基线纳入年龄：**≥45 岁**（研究者已确认 D6）。
- 随访窗口：CHARLS W1→W4（2011–2018）；ELSA W2→W9（2004–2018）；HRS W8→W14（2006–2018/2019）。

### 4.6 统计分析（提取完成后由研究者/分析人员在后续阶段实施）
- 描述统计（连续变量 mean±SD 或中位数 IQR；分类变量频数与百分比）
- Kaplan–Meier 曲线 + log-rank 检验
- Cox 比例风险模型（三个模型）
  - 模型 1：未调整
  - 模型 2：调整年龄、性别
  - 模型 3：进一步调整婚姻状况、教育、吸烟、饮酒、SBP、HbA1c、TC
- Schoenfeld 残差检验 PH 假设
- 限制性三次样条（RCS）剂量反应
- 亚组分析：年龄(<60, 60–<70, ≥70)、性别、教育、吸烟、饮酒、PA、BMI
- 敏感性分析×4：
  1. 排除基线已有移动障碍者
  2. 排除基线有癌症/肺病/CVD 病史者
  3. 排除任何变量缺失者（完整病例）
  4. MICE 多重插补（20 次）

### 5.2 CHARLS ID 处理 —— 核心警告（研究者重点提示，必须严格遵守）
- vvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvv
- CHARLS **2011（第 1 波）的 ID 与之后波次（第 2–4 波）的 ID 构建方式不同**！
- vvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvv

已核实的 ID 规则（来源：codebook p.25–26 及对数据文件实测）：

| 项 | 第 1 波（2011） | 第 2 波及以后 |
|---|---|---|
| 人 ID | `ID_w1`（11 位字符） | `ID`（12 位字符） |
| 户 ID | `householdID_w1`（9 位字符） | `householdID`（10 位字符） |
| 构成 | `ID_w1 = householdID_w1 + pnc`（实测 100% 匹配，n=17,708） | `ID = householdID + pnc`（实测 100% 匹配，n=25,586） |
| 变更原因 | — | 第 2 波起为处理离婚导致的**户籍拆分**，householdID 扩为 10 位（第 10 位为拆分指示位），ID 扩为 12 位 |

实测数据事实（已通过 `pyreadstat` 验证，2026 年操作时）：
- `ID` 对 25,586 行全部非空且唯一；
- `ID_w1` 仅对 17,708 行（第 1 波受访者）非空；其余 7,878 行（第 2 波及以后新进入/补充样本）`ID_w1` 为空串；
- 宽格式下同一人的第 1 波与后续波数据已在同一行，**宽格式内部不需要 ID 跨波匹配**；
- 若日后需与 CHARLS 原始文件（尤其原始血检数据）合并，合并键为：第 1 波原文件用 `ID_w1`（需先重命名为 `ID`），第 2 波及以后原文件用 `ID`。

**操作规程（写死）**：
1. 处理 CHARLS 前，**先通读 codebook Section A（Demographics and Identifiers，p.24–26）**；
2. 不修改任何 ID 列；

### 13.5 HRS PH 假设不满足的处理建议（研究者待决策）

**推荐方案：时间分层（time-dependent）Cox 或"结合随访时限的敏感性验证"两方案并行，以敏感性验证结果作为主结论背书。**

理由：
1. **不丢弃信息**：限制随访（如截尾至 10 年）会损失 HRS 长随访数据（事件高达 4017/5770=70%），而 PH 违反多由远期效应衰减造成，截断反而回避而非解决。
2. **机制合理**：PH 违反提示 eCRF（基线测量）对移动障碍的保护作用随随访时间减弱——这本身是有价值的发现而非缺陷，宜用 eCRF×时间交互项显式建模并报告。
3. **操作可行**：lifelines 支持 `CoxPHFitter` + 时间交互（或分层），或简化处理：报告"按随访期分段（≤5 年 / 5–10 年 / >10 年）的 eCRF HR 表"。
4. **通用做法**：PH 违反时常见"三分位随访期分层 HR + 交互项 p 值"，既满足假设检验又给出可解释的效应变化趋势。

备选：加权 Cox（未加权已决策，暂不用）；分层 Cox（按违反变量分层会掩盖 eCRF 主效应，不推荐为主方案）。

**结论：建议采用"eCRF × 随访期交互 + 分段 HR 报告"，并辅以 ≤10 年随访的敏感性分析验证主结论不变。** 待研究者批准后实施 → 进入 analysis_05 RCS。

### 13.6 AN-3 结果：HRS PH 假设处理（已执行，2026-09-14）

**① 窗口截断 Cox（M3）**（n=2,252，低 eCRF 参照）：

| 窗口 | 中 eCRF HR | 高 eCRF HR | 事件 |
|---|---|---|---|
| ≤5 年 | 0.81 (0.69–0.95), p=0.008 | 0.53 (0.44–0.65), p<0.0001 | 1,096 |
| ≤10 年 | 0.80 (0.70–0.92), p=0.001 | 0.52 (0.44–0.61), p<0.0001 | 1,544 |
| 完整 | 0.79 (0.69–0.90), p=0.0005 | 0.50 (0.43–0.59), p<0.0001 | 1,659 |

- 三个窗口 HR 高度稳定（中 0.79–0.81，高 0.50–0.53）→ **eCRF 保护效应并不随随访时间衰减**，主结论在各窗口均成立。

**② 时间交互项（CoxTimeVaryingFitter，group × log(t)）**：
- `group_mid × log(t)` p<0.0001；`group_high × log(t)` p<0.0001。
- 扩展模型中交互项显著，提示**形式上的 PH 违反**存在，但结合①可知其不影响 eCRF 组间 HR 的稳定性与方向。
- person-period 事件校验 0 不一致（边界 bug 已修复）。

**③ 结案建议**：HRS 主结果采用 M3 完整随访 HR（0.79 / 0.50），并报告"≤5/≤10年窗口 HR 稳定"作为稳健性证据，写明 Schoenfeld 检验提示的 PH 形式性违反及应对，满足审稿要求。

### 13.7 AN-4 结果：RCS 剂量-反应分析（已执行，2026-09-14）

- 方法：模型 3 调整，4 节点（5/35/65/95 百分位），参照=库内 eCRF 中位数。
- **三库均为单调递减曲线，跨越 HR=1**：低于中位 eCRF 者风险显著升高（低值端 HR≈1.6–2.2），高于中位者风险降低。

  - ELSA（n=2,610）：5.19→HR 2.24；9.42→1.0；12.38→0.58。总 Wald p<0.0001。
  - HRS（n=2,252）：4.58→HR 1.92；8.93→1.0；11.77→0.62。总 Wald p<0.0001。

### 13.9 亚组设计局限性、肥胖悖论与吸烟/PA"悖论"的详细解释（供论文写作引用）

> 本节回答数据分析中出现的若干"反直觉"发现，说明其科学含义与报告方式。**核心论点：这些发现多为"复合指标（eCRF）的成分被用于分层/调整"导致的方法学现象，而非 eCRF 公式本身的错误。** 出处均为 AN-6 与后续诊断的结果。

#### 13.9.1 eCRF 是"复合指数"，其成分同时扮演三个角色

eCRF 公式本质是年龄、age²、BMI、WC、rHR、MVPA、吸烟的**线性组合**：

```
eCRF = 常数项 + β_age·age + β_age2·age² + β_bmi·BMI + β_wc·WC + β_rhr·rHR
       + β_mvpa·MVPA + β_smoke·吸烟
```

因此同一变量（如 BMI）在分析中同时存在三个层面：
1. **作为 eCRF 的内部成分**（被公式"吃掉"一次）；
2. **作为协变量进入 Cox 模型**（再调整一次）；
3. **作为亚组分层变量**（再分层一次）。

当"分层"发生时，层内该成分差异被压缩，层间比较的"高 vs 低 eCRF"实际反映的只是**该层内剩余成分**的差异（如年龄、其他测量），导致亚组 HR 数值与全样本呈现"漂移"。这是**条件化（conditioning）对复合暴露的固有影响**，不属于数据错误。

#### 13.9.2 现象一："当前吸烟者亚组 HR 更小"

- 现象：吸烟亚组中"高 vs 低 eCRF"的 HR 数值小于从不吸烟组（详见 AN-6）。
- 原因①（人群构成混杂）：诊断显示当前吸烟者在全体中更年轻(59.0 vs 从不61.0)、更瘦(BMI 24.1)、心率更快但运动比例不低()，故其 eCRF 绝对值反而偏高——公式"吸烟减分"被年龄/BMI优势抵消。
- 原因②（参照组构成不同）：各吸烟亚组内部"低 eCRF 组"是**不同的人群**（年龄/BMI/心率/MVPA 差异显著，诊断 C），亚组 HR 不在同一基准上，**不可横向比较大小**。
- 关键证据（吸烟本身有害，方向未错）：不调整 eCRF 时，当前吸烟 vs 从不吸烟移动障碍 **HR=1.20（95%CI 1.10–1.30, p<0.0001）**，曾吸烟 HR=1.10，**吸烟升高移动障碍风险**——符合常理。
- 报告建议：主分析报告吸烟的**直接效应**（HR≈1.20）；亚组分析只报告**各亚组内方向一致性**，不比较亚组间 HR 大小。

#### 13.9.3 现象二："MVPA 与 eCRF 的'低'"——非强度问题，而是分层锁定成分

- 事实：有 MVPA 者 eCRF 更高（10.05 vs 8.99，诊断 B）✅ 公式方向正确。
- 现象（亚组）：按 MVPA 分层后，"有 MVPA"层内 eCRF 高/低差异转由 BMI/WC/rHR/年龄主导，HR 数值较无 MVPA 层略有不同（0.856 vs 0.732）。
- 解释：该现象**不表示"剧烈活动不促进心肺"**，而是**分层消除了 MVPA 成分的贡献**后，剩余成分主导亚组内差异。
- 生理注脚（供讨论）：心肺耐力（VO2max）主要由**规律中低强度有氧耐力训练**提升；高强度的间歇/力量训练对 VO2max 增益有限。研究中 MVPA 作为"是否保持运动习惯 ≥2 次/周"的行为指标，反映运动习惯而非强度特异性。此点可作为论文讨论的科学背景，但**不应**据此否定 MVPA 在人群水平的保护意义（全样本 MVPA 较高者事件率更低）。
- 报告建议：报告全样本 MVPA 与移动障碍的关系（观测：有 MVPA 者粗发生率 0.570 vs 无 0.611），以行为层面证据为主。

#### 13.9.4 现象三："肥胖者 HR 更低"——经典"肥胖悖论"（obesity paradox），务必谨慎解读

- 数据事实（诊断 D）：
  - eCRF：肥胖 8.07 < 超重 9.54 < 正常 10.64（eCRF 公式对肥胖正确"降分"）；
  - **移动障碍粗发生率**：肥胖 0.716 > 超重 0.602 > 正常 0.509（**绝对风险上肥胖确实不利**）；
  - 肥胖亚组内：低 eCRF 0.748 → 中 0.694 → 高 0.647（肥胖者中心肺功能最差者风险确实最高）。
- 解读：上述组合 = 典型的"肥胖悖论"：在肥胖人群内部，"BMI 高但仍维持较好心肺功能"者是特殊的健康子群（代谢健康型肥胖），其移动障碍风险相对低。**但绝不等于肥胖本身有利**，因为肥胖人群的绝对风险最高。
- 报告建议：在论文中明确区分"①肥胖本身升高移动障碍绝对风险"与"②肥胖者内部 eCRF 高者风险较低"两个层面；后者的生物学机制（肌力、代谢健康、脂肪分布等）作为讨论。**避免任何可能被误读为"肥胖有益"的表述。**

#### 13.9.5 为什么结论仍稳健（防御性叙述模板，可直接用于 Methods/Discussion）

1. **主分析（全样本 M2/M3）**：三库一致，中/高 eCRF 较低的移动障碍风险（HR 0.50–0.82），完全调整后仍显著，方向与 RCS（单调递减）一致。
2. **亚组分析**：各亚组内"低→高 eCRF"的事件率/发生率均呈单调下降（绝对风险辅助证据，无反常反转）。
3. **交互检验**：年龄、性别、吸烟、PA、BMI 的交互 p 均 >0.05（教育 p<0.001、饮酒 p=0.017 达名义显著但方向一致、幅度小）→ 无强异质性证据。
4. **局限说明**：亚组间 HR 大小比较受"复合指标成分分层"与参照组构成影响，不作为效应修饰的定量判据；肥胖悖论与吸烟悖论按 §13.9.2–13.9.4 如实报告与讨论。

### 13.16 数据修正记录：marital 编码 bug（发现于 Table 1 制作，2026-09-14）

**问题**：STEP-04 三个基线脚本中 marital 二分映射逻辑错误：
```python

# 正确写法（1 或 3 均编码为 1=已婚或有伴侣）

```
- 影响范围：CHARLS 1,278 例、ELSA 316 例、HRS 161 例（编码 3=有伴侣）未被计入"已婚或有伴侣"，错误地留在 3 值上；少数 HRS 编码 2 未规范。
- **后果**：`marital` 不再是纯 0/1，导致 Table 1 分类行（Married/partnered + Other 合计 <100%）及所有含 marital 的 Cox 模型（M3、亚组、敏感性）使用错误编码。

**处理**：修正三个 `step04*_baseline.py` 脚本 → 重跑 step04→step05→07→08→09→11 → 重跑全部分析（an1–an10）→ 重新生成 Table 1。旧结果备份至 `output_v1_before_marital_fix`。

**对结论的影响验证**：marital 修正后所有分析结果几乎不变（主分析高 eCRF HR：CHARLS 0.744 vs 0.741、ELSA 0.585 vs 0.585、HRS 0.503 vs 0.503；亚组交互 p、敏感性、MICE、AN-9/10 均一致）——因 marital 在 M3 中本就不显著（三库 p>0.05）。**结论不变，但编码现已正确。**

**教训（写入 H4/H5 范畴）**：编码变换务必使用 `np.where` 显式映射并**用 Table 1 分类行合计=100% 校验**；本 bug 正是通过 Table 1 检查发现。

- 不做任何隐讳或淡化。

**② HRS PH 假设"统计上违反、实质上未失效"的论文论述模板**：
- 陈述事实：HRS 中 Schoenfeld 残差检验提示部分协变量（eCRF 组、年龄等）p<0.05，即 PH 假设在统计上被违反。
- 给出应对证据（三窗口稳定性）：eCRF 组 HR 在 ≤5 年（0.53）、≤10 年（0.52）、完整随访（0.50）三个窗口高度稳定 → 效应方向与幅度不随时间实质改变。
- 给出解释：HRS 随访最长、事件率最高（70%）、样本量大，Schoenfeld 检验对其微小风险比漂移更敏感（大样本下微小偏离即可达显著）。
- 结论用语（可直接采用）：
  > "尽管 HRS 中比例风险假设在形式检验上遭到违反（Schoenfeld 残差检验 p<0.05），但 eCRF 组间风险比在 ≤5 年、≤10 年及全程随访窗口中高度稳定（HR 0.50–0.53），表明该形式的 PH 违反不改变 eCRF 与移动障碍关联的方向与幅度；我们据此将完整随访的 Cox 结果作为 HRS 主结果，并在敏感性分析中报告相似结论。"
